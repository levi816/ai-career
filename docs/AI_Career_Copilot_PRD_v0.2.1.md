------------------------------------------------------------------------

# 1. 产品定位

AI Career Copilot 是一个基于用户职业数据沉淀的 AI 求职助手。

长期目标：

帮助用户完成：

职业规划 → 简历优化 → 岗位匹配 → 投递管理 → 面试复盘 → Offer决策 →
职业成长

------------------------------------------------------------------------

    用户画像

    ↓

    AI职业规划

    ↓

    ↓

    JD智能匹配

    ↓

    Application投递管理

    ↓

------------------------------------------------------------------------

# 3. 核心功能

## 3.1 用户画像

用户输入：

-   当前状态
-   所在城市
-   目标城市
-   教育经历
-   技能
-   项目经历
-   职业目标

AI输出：

-   职业方向
-   推荐岗位
-   优势
-   能力差距
-   提升建议

------------------------------------------------------------------------

## 3.2 AI职业规划

输入：

User Profile

输出：

-   推荐方向
-   推荐岗位
-   优势证据
-   能力差距
-   提升建议

取消：

行动计划。

------------------------------------------------------------------------

## 3.3 AI简历助手

MVP支持：

-   文本简历输入
-   简历分析
-   JD匹配优化

暂不支持：

-   PDF解析
-   DOCX解析
-   OCR

------------------------------------------------------------------------

## 3.4 Application管理

Application是核心业务对象。

关系：

    Application

    ↓

    JD

    ↓

    ResumeVersion

    ↓

    Interview

字段：

    id

    user_id

    company

    position

    jd_content

    status

    custom_status

    resume_version_id

    created_time

状态：

默认状态：

-   待投递
-   已投递
-   面试中
-   Offer
-   已结束

支持：

custom_status

用于用户自定义阶段。

------------------------------------------------------------------------

## 3.5 JD匹配

取消：

match_score。

不展示：

85%匹配度。

采用：

Match Level + Confidence + Evidence。

输出：

Match Level：

-   Strong Match
-   Partial Match
-   Weak Match

Confidence：

-   High
-   Medium
-   Low

Evidence：

说明判断依据。

------------------------------------------------------------------------

## 3.6 AI面试复盘

MVP输入：

文本记录。

包含：

-   面试问题
-   用户回答

输出：

-   总结
-   优势
-   不足
-   改进建议
-   高频问题

暂不支持：

-   音频
-   录屏

------------------------------------------------------------------------

# 4. Memory设计

MVP实现：

结构化上下文记忆。

包括：

-   User Profile
-   Application记录
-   Interview记录
-   AIReport
-   UserCorrection

不实现：

-   向量记忆
-   Agent Memory

-   结构化输出
-   可解释

虚假精确评分。
