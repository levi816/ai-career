# AI Career Copilot 用户研究与竞品分析文档

## 1. 用户研究

### 1.1 用户求职流程分析

典型求职流程：

    认识自己
    ↓
    确定职业方向
    ↓
    制作简历
    ↓
    寻找岗位
    ↓
    投递申请
    ↓
    准备面试
    ↓
    面试复盘
    ↓
    Offer选择
    ↓
    职业发展

目前市场上的产品通常只覆盖其中某一个阶段。

------------------------------------------------------------------------

## 1.2 用户核心痛点

### 痛点1：职业规划阶段

用户不知道：

-   自己适合什么岗位
-   自己能力是否匹配目标岗位
-   应该如何制定准备路线

当前解决方式：

-   搜索资料
-   咨询朋友
-   使用ChatGPT

问题：

信息零散，缺少长期记录。

------------------------------------------------------------------------

### 痛点2：简历制作阶段

用户不知道：

-   项目经历如何表达
-   如何突出个人价值
-   如何针对不同JD调整简历

------------------------------------------------------------------------

### 痛点3：投递管理阶段

用户同时投递多个岗位时：

-   难以管理投递状态
-   容易遗漏跟进
-   无法分析投递效果

------------------------------------------------------------------------

### 痛点4：面试阶段

用户缺少：

-   面试复盘
-   问题沉淀
-   能力成长追踪

------------------------------------------------------------------------

### 痛点5：Offer决策阶段

用户需要综合：

-   薪资
-   城市
-   行业
-   成长空间
-   职业规划

但缺少智能决策辅助。

------------------------------------------------------------------------

# 2. 市场竞品分析

## 竞品分类

1.  综合招聘平台
2.  AI简历工具
3.  AI面试工具
4.  AI求职助手

------------------------------------------------------------------------

# 3. 综合招聘平台

代表：

-   BOSS直聘
-   LinkedIn

## 产品定位

解决：

找工作。

## 优点

-   岗位资源丰富
-   招聘效率高

## 缺点

-   缺少完整求职过程管理
-   缺少个人成长反馈

## 产品机会

AI Career Copilot
不替代招聘平台，而是在招聘之后帮助用户管理整个求职生命周期。

------------------------------------------------------------------------

# 4. AI简历工具

代表：

-   Teal
-   Huntr

## 核心能力

-   简历优化
-   JD匹配
-   Job Tracker

## 优点

-   简历优化专业
-   数据化管理申请

## 缺点

-   缺少面试闭环
-   缺少长期职业画像

## 产品机会

连接：

简历 → 岗位 → 面试 → Offer

形成完整闭环。

------------------------------------------------------------------------

# 5. AI面试工具

代表：

-   牛客

## 核心能力

-   AI模拟面试
-   面试题库
-   面试评价

## 优点

-   面试训练专业
-   场景真实

## 缺点

-   面试前后割裂
-   缺少个人成长数据库

## 产品机会

建立个人面试成长档案。

------------------------------------------------------------------------

# 6. AI求职助手

## 核心能力

-   简历解析
-   JD分析
-   简历优化
-   岗位匹配

## 缺点

多数产品仍关注：

帮助用户获得面试机会。

而不是：

管理完整职业过程。

------------------------------------------------------------------------

# 8. 产品机会分析

市场缺口：

目前缺少一个连接：

用户画像 + 求职目标 + 简历数据 + 岗位数据 + 面试数据 + Offer数据

的长期职业AI助手。

------------------------------------------------------------------------

# 9. 核心差异化

## 9.1 从工具到助手

传统产品：

用户主动操作。

AI Career Copilot：

AI主动发现问题并提供建议。

------------------------------------------------------------------------

## 9.2 从单点优化到全流程管理

覆盖：

职业规划 → 简历 → 投递 → 面试 → Offer → 成长

------------------------------------------------------------------------

## 9.3 从短期使用到长期陪伴

沉淀：

-   用户职业数据
-   面试经验
-   成长记录

形成个人职业数据库。

------------------------------------------------------------------------

# 10. 产品定位总结

AI Career Copilot
是一个基于用户长期职业数据，为求职者提供规划、执行、复盘和决策支持的 AI
求职伙伴。
