## Task

-   Next.js项目创建

-   PostgreSQL连接
-   基础目录结构

验收：

项目可以正常启动。

------------------------------------------------------------------------

# 4. Phase 2 用户画像模块

## 开发内容

创建Profile页面。

用户输入：

-   当前状态
-   所在地
-   目标城市
-   教育经历
-   技能
-   项目经历
-   职业目标

AI输出：

-   职业画像
-   优势
-   不足
-   推荐方向

验收：

用户完成填写后生成职业画像。

------------------------------------------------------------------------

# 5. Phase 3 AI简历助手

## 开发内容

实现：

-   简历上传
-   文件解析
-   AI分析

AI输出：

-   简历评分
-   优势
-   问题
-   修改建议

验收：

用户上传简历后获得优化报告。

------------------------------------------------------------------------

# 6. Phase 4 JD分析

## 开发内容

用户输入JD。

AI输出：

-   岗位要求
-   技能关键词
-   用户匹配度
-   能力差距

验收：

生成岗位分析结果。

------------------------------------------------------------------------

# 7. Phase 5 Application管理

## 开发内容

实现：

-   创建岗位申请
-   保存JD
-   关联简历
-   修改状态
-   Timeline

状态：

-   待投递
-   已投递
-   面试中
-   Offer
-   已结束

验收：

用户可以管理求职进度。
