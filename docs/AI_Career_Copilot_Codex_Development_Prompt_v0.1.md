# AI Career Copilot Codex Development Prompt v0.1

## 项目背景

AI Career Copilot 是一款 AI 求职助手 Web 产品，帮助用户完成：

职业规划 → 简历优化 → 岗位匹配 → 投递管理 → 面试复盘 → Offer决策 →
职业成长。

产品定位：

通过长期沉淀用户职业数据，让 AI
成为用户的职业成长助手，而不是一次性聊天工具。

------------------------------------------------------------------------

## MVP目标

完成一个可展示的 AI 产品 Demo，验证：

AI 是否能够帮助求职者完成完整求职闭环。

------------------------------------------------------------------------

# 开发原则

1.  优先完成核心闭环。
2.  不提前开发Agent、自动投递等高级功能。
3.  保持架构可扩展。
4.  每完成模块输出变更说明和测试方式。
